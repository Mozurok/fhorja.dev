# Deletion ledger

One row per rule, citation or surface removed while Fhorja moved to a default path that carries its
own chain (ADR-0184, ADR-0186) and then stopped giving that path a name (ADR-0207). This file is not a rule and it is not an ADR. It exists so that "what did we delete
and why" has an answer that is not `git log`, because a CRUD over the rules is only safe if the D
half stays legible afterwards.

Every row names what went, where it lived, why, and what carries its intent now. `nothing,
deliberately` is a valid answer and is preferred over inventing a replacement.

## Standing decisions this ledger operates under

- **The default path has no name (ADR-0207).** It chains; a heavier path is entered on a named
  disqualifier (ADR-0184). This ledger's first rows call that path Express, the name it had when they
  were written.
- **A human stop survives for four named reasons**, as `WORKFLOW_OPERATING_SYSTEM.md` `### Adaptive
  handoff` states them: an act whose audience is not bounded; a decision that changes what the product
  is; a cost or loop ceiling; and **a check of the work the agent cannot honestly run on itself**.
  ADR-0200 replaced "outward or irreversible" with the audience test on 2026-09-16. A boundary surface
  (auth, payments, compliance, PII, multi-tenant isolation) is not a stop: it makes the run deeper, for
  example a second blinded review of the plan (ADR-0208). The fourth reason was added on 2026-08-31
  after a six-dimension survey found that the first three would have deleted the only rule preventing a
  chaining agent from satisfying its own human-verdict checkpoint. On an attended run on a git
  repository with a configured remote, ADR-0233 turned reasons 2 and 4 into a recorded provisional
  decision and a listed unverified check rather than a wait, leaving only reason 1 (short of a reason
  3 ceiling); without a remote all four still stop the chain, and a declared assisted mode brings
  back every stop ADR-0233 removed.
- **ADRs are frozen, not deleted.** They stop being the normative source and stay as history.
  Measured alternative: deleting them breaks 1590 references and crashes the structural runner,
  and buys nothing the freeze does not.
